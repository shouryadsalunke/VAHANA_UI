# VAHANA - Car Rental Website

VAHANA is a front-end car rental website developed as part of a Web Development (WDD) college project. It allows users to browse vehicles, explore rental prices, and make demo bookings through a simple and user-friendly interface.

## Features

- Browse cars and two-wheelers.
- Search for vehicles by name.
- Filter vehicles by category and budget.
- View vehicle details and daily rental prices.
- Book vehicles by entering customer details and rental dates.
- Calculate the estimated rental cost automatically.
- Validate form inputs.
- Demonstrate a basic login interface.
- View booking history saved in browser local storage.
- Responsive design with a black, red, and off-white theme.

## Technologies Used

- HTML5 - Website structure and forms.
- CSS3 - Styling, layouts, colours, and responsive design.
- JavaScript - Search, filtering, form validation, and rental calculations.
- CSV - Sample vehicle data.
- Local Storage - Saving demo booking information in the browser.

## How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Ensure all HTML, CSS, JavaScript, CSV, and image files are present.
4. Open `index.html` using the Live Server extension.
5. Explore the vehicle catalogue, try the filters, and test the booking form.

Note: Live Server is recommended if the website loads vehicle data from the CSV file using JavaScript.

## Working

The website uses JavaScript to display vehicle information, search and filter vehicles, validate user inputs, and calculate rental costs based on the selected dates and daily rental rates.

Vehicle information is stored in a CSV file, while demo booking information is saved using the browser's local storage.

## Project Scope

VAHANA is an educational front-end project created to practise fundamental web development concepts, including HTML elements, CSS styling, JavaScript variables, arrays, functions, loops, conditional statements, event handling, DOM manipulation, form validation, and local storage.

This project is a demonstration and does not provide real vehicle reservations, payment processing, or production-level authentication. Vehicle prices and availability are illustrative.
